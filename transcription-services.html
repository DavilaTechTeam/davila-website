Before transcription starts

Audio quality and project details matter.

Clear recordings, correct names and useful context can improve efficiency and reduce questions during transcription.

  • Provide the best-quality recording available
  • Identify speakers when possible
  • Share names and specialized terminology
  • State the intended use
  • Provide the real deadline
  • Flag rush work immediately

Recording to written text

Describe the transcript you need before sending the recording.

A transcript turns recorded speech into text. Translating that text into another language is a separate part of the scope, so identify both needs at intake.

Describe the source

Tell us the recording length, language, number of speakers and any background noise. Identify overlapping voices or sections with poor audio when you request a quote.

Specify the output

Tell us whether you need speaker labels, timestamps or a particular file format. If a legal proceeding has special transcript requirements, include them for review before the assignment is confirmed.

Add translation when needed

If the recipient needs the written record in another language, include the target language and deadline. Review document translation services or legal document translation services for the written translation scope.
